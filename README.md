# مَرْجِع — من المعرفة إلى الممارسة الواعية

موقع ثابت (HTML/CSS/JS) بلا أي أدوات بناء. افتح `index.html` مباشرة أو ارفع المجلد كما هو.

## هيكل الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة وكل الأقسام والنوافذ |
| `data/content.js` | الأعضاء، المقالات، الكتب، مواقف التدريب، أسئلة الاختبار، نص العرض التعريفي |
| `data/guide.js` | **شرح اللائحة (١٤ موضوعًا)، دليل تجنّب المخالفة (٣٠ بندًا)، الأخلاقيات (٩ مواقف)** مع المادة والصفحة لكل عنصر |
| `css/base.css` | الأنماط الأصلية للمشروع (محفوظة كما هي) |
| `css/sections.css` | أنماط أقسام اللائحة والأخلاقيات والهوية التحريرية (منقولة من نسخة الأخلاقيات) |
| `css/upgrade.css` | الإصلاحات والأقسام الجديدة وتفاعلات المؤشر وضبط خط Cairo |
| `css/intro.css` · `js/intro.js` | الافتتاحية التفاعلية ثلاثية الأبعاد |
| `js/app.js` | منطق الواجهة (القوائم، النوافذ، التدريب، الاختبار، المكتبة، المسودات) |
| `js/guide.js` | محرك شرح اللائحة ودليل الوقاية والأخلاقيات ونقاط الدخول |
| `js/motion.js` | حركات الماوس (تتعطل تلقائيًا على اللمس وعند «تقليل الحركة») |
| `assets/` | الشعار وصور الأعضاء التجريبية |

## تعديلات شائعة

- **إضافة عضو أو مقال حقيقي:** أضفه في `data/content.js` مع `sample: false`. المقال لا يظهر إلا إذا كانت حالته `status: "published"`؛ الحالات المتاحة: `draft` ← `review` ← `published`. ثم أضف بطاقته في `index.html` بنفس شكل البطاقات الموجودة.
- **إضافة التعليق الصوتي للافتتاحية:** ضع التسجيل في `assets/intro-voice.mp3`، ثم في `data/content.js` اجعل `voiceFile: "assets/intro-voice.mp3"` وعدّل `duration` لكل مشهد ليطابق توقيت التسجيل. نص التعليق موجود في نفس المكان (`caption`).
- **تغيير الخط:** رابط Google Fonts في أعلى `index.html`، واسم الخط في `body` داخل `css/base.css`.

## قاعدة تحرير المحتوى النظامي

لا تُضاف مادة أو فقرة أو صفحة أو مبلغ إلى `data/guide.js` إلا بعد مطابقته على صورة الصفحة في ملف اللائحة. ما لم يُطابق يُكتب «قيد المراجعة» (في الدليل: `link: null`). راجع `QA_AR.md` لقائمة ما تم التحقق منه وما يحتاج تدقيقًا نظاميًا.

## النشر على GitHub Pages

1. أنشئ مستودعًا عامًا جديدًا في حسابك (مثلًا `marji`).
2. ارفع `index.html` و`README.md` من صفحة Upload في الجذر. ثم لكل مجلد (`css` و`js` و`data` و`assets`) افتح `…/upload/main/اسم-المجلد` وارفع الملفات التي بداخله؛ زر «choose your files» لا يرفع مجلدات.
3. من Settings ← Pages: اختر Source = `Deploy from a branch`، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة تقريبًا يعمل الموقع على: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## ملاحظات تحريرية

- شروح اللائحة ودليل الوقاية توعوية وغير ملزمة، ومرتبطة بمادة وصفحة في ملف اللائحة المرفق للمشروع. **تحقق من أي تحديث رسمي لاحق قبل الإطلاق.**
- الأعضاء والمقالات الحالية عيّنات افتراضية وموسومة بذلك في الواجهة، وصورها مولّدة بالذكاء الاصطناعي.
- أغلفة الكتب تصميمات تعريفية من مَرْجِع؛ الكتب المحفوظة الحقوق لا تُعاد استضافتها.
